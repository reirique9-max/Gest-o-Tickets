# 🛠️ Sistema de Gestão de Tickets de Suporte

## 📖 Sobre o Projeto
Este é um sistema de linha de comandos (CLI) desenvolvido em Python para simular a criação, listagem e resolução de tickets de atendimento ao cliente. 

O objetivo deste projeto prático é aplicar conceitos de lógica de programação, manipulação de dicionários e listas em Python, e simular a lógica de *backoffice* que antecede a implementação de uma base de dados relacional (Entity-Relationship).

## 🚀 Tecnologias Utilizadas
* **Python 3.x**: Lógica principal da aplicação.
* **Git/GitHub**: Versionamento e documentação.
